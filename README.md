# Data Exploration and Preparation – CA1 (Energy)

How do countries make their electricity, and how clean is it? (2000–2022)

## Dataset
Our World in Data – Energy dataset: https://github.com/owid/energy-data

## How to run
1. install.packages(c("dplyr","tidyr","ggplot2","corrplot"))
2. Keep owid-energy-data.csv in the same folder as the script
3. Open CA1_energy_analysis.R in RStudio and click Source
